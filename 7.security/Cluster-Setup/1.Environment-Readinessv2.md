
# 🐐 Kubernetes Goat Deployment Guide (CKS Practice)

## 📌 Overview
Kubernetes Goat is an intentionally vulnerable Kubernetes cluster environment designed to help you practice **Certified Kubernetes Security Specialist (CKS)** scenarios.

---

## 🔗 References
- GitHub Repo: https://github.com/madhuakula/kubernetes-goat  
- Official Guide: https://madhuakula.com/kubernetes-goat/

---

## ✅ Prerequisites

### 🖥️ Infrastructure
- Kubernetes cluster (v1.24+ recommended)
- kubectl configured
- Admin access to cluster

### ⚙️ Tools
- Git
- Bash shell
- (Optional) Helm

### 🌐 Networking
- Ingress controller (Traefik / NGINX)
- DNS entry pointing to LoadBalancer IP (optional)

---

## 🚀 Step 1: Clone Repository

```bash
git clone https://github.com/madhuakula/kubernetes-goat.git
cd kubernetes-goat
```

---

## 🚀 Step 2: Deploy Kubernetes Goat

```bash
chmod +x setup-kubernetes-goat.sh
./setup-kubernetes-goat.sh
```

### 🔍 What this does:
- Deploys vulnerable workloads
- Creates namespaces
- Sets up RBAC misconfigurations
- Deploys services & jobs

---

## 🔍 Step 3: Verify Deployment

```bash
kubectl get pods -A
kubectl get svc
```

Ensure all pods are in **Running** state.

---

## 🌐 Step 4: Access Application

### Option 1: Port Forward (Quick Test)

```bash
kubectl port-forward svc/kubernetes-goat-home-service 8080:80
```

Access:
👉 http://localhost:8080

---

### Option 2: Ingress (Recommended)

Create `IngressRoute` (Traefik):

```yaml
apiVersion: traefik.io/v1alpha1
kind: IngressRoute
metadata:
  name: goat
  namespace: default
spec:
  entryPoints:
    - web
  routes:
    - match: Host(`goat.example.com`)
      kind: Rule
      services:
        - name: kubernetes-goat-home-service
          port: 80
```

Apply:

```bash
kubectl apply -f goat-ingress.yaml
```

## 🔥 Step 5: Practice Scenarios

### 🔓 Attack Surface
- NodePort exposure
- Privileged containers
- Weak RBAC
- Secrets leakage

### 🔒 Defensive Tasks
- Apply NetworkPolicies
- Harden SecurityContext
- Restrict RBAC
- Scan images (Trivy)
- Monitor runtime (Falco)
