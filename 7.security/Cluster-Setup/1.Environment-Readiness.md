## ⚙️ Prerequisites

- 🧠 Kubernetes Cluster (K3s / Minikube / EKS / GKE / AKS)  
- 🔧 kubectl configured  
- 📦 Git installed  
- 🧰 Helm (for ingress, optional)

```bash
kubectl get nodes
```

---

## 📥 Step 1: Clone Repository

```bash
git clone https://github.com/microservices-demo/microservices-demo
cd microservices-demo
```

---

## 🚀 Step 2: Deploy Sock Shop

```bash
kubectl apply -f deploy/kubernetes/complete-demo.yaml
```

---

## ✅ Step 3: Verify Deployment

```bash
kubectl get deploy,pod,svc -n sock-shop
```

✔ Pods → Running  
✔ Deployments → READY  
✔ Services → Created

## 🌍 Step 5: Access via Ingress

### 🔹 Install NGINX Ingress

```bash
helm repo add ingress-nginx https://kubernetes.github.io/ingress-nginx
helm repo update

helm install nginx-ingress ingress-nginx/ingress-nginx \
  --namespace ingress-nginx --create-namespace
```

---

### 🔹 Or Use Traefik (K3s)

```bash
kubectl get pods -n kube-system | grep traefik
```

---

## 📝 Create Ingress

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: sockshop-ingress
  namespace: sock-shop
  annotations:
    kubernetes.io/ingress.class: nginx
spec:
  rules:
  - host: sockshop.local
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: front-end
            port:
              number: 80
```

```bash
kubectl apply -f sockshop-ingress.yaml
```

Add:
```
<NODE-IP> sockshop.local
```

## ⚙️ Operations

### 🔄 Restart
```bash
kubectl rollout restart deployment front-end -n sock-shop
```

### 📈 Scale
```bash
kubectl scale deployment front-end --replicas=3 -n sock-shop
```

### 📜 Logs
```bash
kubectl logs -f <pod-name> -n sock-shop
```

---

## 🛠️ Troubleshooting

### 🔍 Describe
```bash
kubectl describe pod <pod-name> -n sock-shop
```

### ⚠️ Common Issues

- 🚫 ImagePullBackOff → Check network  
- 🔁 CrashLoopBackOff → Inspect logs  
- 🌐 No access → Check NodePort / Ingress
