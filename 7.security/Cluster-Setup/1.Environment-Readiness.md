# 🧦 Sock Shop Deployment Guide on Kubernetes

## 📌 Overview
This guide walks you through deploying the **Sock Shop microservices demo** on Kubernetes with a clean and production-friendly approach.

---

## ⚙️ Prerequisites

Ensure you have:

- 🧠 Kubernetes Cluster (K3s / Minikube / EKS / GKE / AKS)
- 🔧 kubectl configured
- 📦 Git installed

### 🔍 Verify cluster access
```bash
kubectl get nodes
```

---

## 📥 Step 1: Clone Repository

```bash
git clone https://github.com/microservices-demo/microservices-demo
cd microservices-demo
```

---

## 🚀 Step 2: Deploy Application

```bash
kubectl apply -f deploy/kubernetes/complete-demo.yaml
```

---

## ✅ Step 3: Verify Deployment

```bash
kubectl get deploy,pod,svc -n sock-shop
```

### ✔ Expected:
- Pods → `Running`
- Deployments → `READY 1/1`
- Services → Created

---

## 🌐 Step 4: Access Application

### 🔎 Check frontend service
```bash
kubectl get svc front-end -n sock-shop
```

### 📌 Example Output
```
NodePort: 30001
```

### 🌍 Access URL
```
http://<NODE-IP>:30001
```

### 🔍 Find Node IP
```bash
hostname -I
```

---

## 🧱 Step 5: Architecture Overview

| 🧩 Component | 🔧 Type | 💾 Backend |
|------------|--------|-----------|
| front-end  | NodePort | — |
| carts      | ClusterIP | MongoDB |
| catalogue  | ClusterIP | MySQL |
| orders     | ClusterIP | MongoDB |
| user       | ClusterIP | MongoDB |
| payment    | ClusterIP | — |
| shipping   | ClusterIP | — |
| rabbitmq   | ClusterIP | Queue |
| session-db | ClusterIP | Redis |

---

## ⚙️ Step 6: Operations

### 🔄 Restart Service
```bash
kubectl rollout restart deployment front-end -n sock-shop
```

### 📈 Scale Service
```bash
kubectl scale deployment front-end --replicas=3 -n sock-shop
```

### 📜 View Logs
```bash
kubectl logs -f <pod-name> -n sock-shop
```

---

## 🛠️ Step 7: Troubleshooting

### ❌ Pod Issues
```bash
kubectl describe pod <pod-name> -n sock-shop
```

### 📜 Check Logs
```bash
kubectl logs <pod-name> -n sock-shop
```

### ⚠️ Common Problems

- 🚫 ImagePullBackOff → Check internet/Docker Hub limits  
- 🔁 CrashLoopBackOff → Check logs  
- 🌐 No access → Verify NodePort / firewall  

---

## 🧹 Step 8: Cleanup

```bash
kubectl delete -f deploy/kubernetes/complete-demo.yaml
```

---

## 🔐 Step 9: Production Recommendations

- 🌍 Use Ingress Controller
- 🔒 Enable TLS (cert-manager)
- 📊 Add Monitoring (Prometheus + Grafana)
- ⚖️ Configure Resource Limits
- 🛡️ Apply Network Policies
