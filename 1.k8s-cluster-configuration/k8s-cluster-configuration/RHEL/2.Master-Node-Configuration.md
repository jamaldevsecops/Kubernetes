## 🚀 Master Setup

### 🔧 Initialize Cluster
```bash
kubeadm config images pull --cri-socket unix:///var/run/crio/crio.sock
kubeadm init \
  --cri-socket unix:///var/run/crio/crio.sock \
  --pod-network-cidr=10.244.0.0/16 \
  --control-plane-endpoint kubeapi.nagad.com
```

### 🔑 Configure kubectl
```bash
mkdir -p $HOME/.kube
cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
chown $(id -u):$(id -g) $HOME/.kube/config
```

### 🛡️ Configure SELinux for Kubernetes (CRI-O)

Install required SELinux and container policy packages:

```bash
dnf install -y policycoreutils-python-utils setools-console audit
dnf install -y container-selinux selinux-policy selinux-policy-targeted
```

Enable required SELinux boolean:

```bash
setsebool -P container_manage_cgroup on
```

Restore SELinux contexts for Kubernetes and container runtime paths:

```bash
restorecon -RFv /var/lib/containers
restorecon -RFv /var/lib/kubelet
restorecon -RFv /etc/cni
restorecon -RFv /opt/cni
restorecon -RFv /etc/kubernetes
```

Restart services to apply changes:

```bash
systemctl restart crio
systemctl restart kubelet
```

### 🌐 Install Calico
```bash
curl -O https://raw.githubusercontent.com/projectcalico/calico/v3.30.7/manifests/calico.yaml
```

Edit CIDR `192.168.0.0/16` to `10.224.0.0/16`:
```yaml
sed -i 's/# - name: CALICO_IPV4POOL_CIDR/- name: CALICO_IPV4POOL_CIDR/' calico.yaml
sed -i 's/#   value: "192.168.0.0\/16"/  value: "10.244.0.0\/16"/' calico.yaml
```
Verify: 
```bash
grep -nA1 "CALICO_IPV4POOL_CIDR" calico.yaml
```

Apply:
```bash
kubectl apply -f calico.yaml
```
