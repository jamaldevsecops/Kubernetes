# 👷 Kubernetes Worker Node Runbook

## 🔗 Join Cluster

```bash
kubeadm join kubeapi.nagad.com:6443   --token <TOKEN>   --discovery-token-ca-cert-hash sha256:<HASH>   --cri-socket unix:///var/run/crio/crio.sock
```

---

## 🔍 Verification

### On Worker:
```bash
systemctl status kubelet
crictl info
```

### On Master:
```bash
kubectl get nodes
```

Expected:
- Worker node shows `Ready`

---

## 🛠️ Troubleshooting

### ❌ Node Not Ready
```bash
journalctl -u kubelet -xe
```

### ❌ Cannot Pull Images
- Check proxy
- Check CRI-O

```bash
systemctl status crio
```
