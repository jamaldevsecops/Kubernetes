# 🧱 Common Node Preparation Runbook
## RHEL 8 + CRI-O + Kubernetes 1.35
### For Both Master and Worker Nodes

> Use this runbook on **every node** before running the separate **master** or **worker** runbooks.

---

# 📌 Input Values

Update these values as needed for your environment.

- **Kubernetes repo version:** `v1.35`
- **CRI-O repo version:** `v1.35`
- **Pod CIDR:** `10.244.0.0/16`
- **API endpoint:** `kubeapi.nagad.com`
- **Proxy:** `http://192.168.20.200:9999`
- **Master IP example:** `192.168.20.126`

---

# 1️⃣ Set Hostname

## 👑 Master example
```bash
hostnamectl set-hostname ngd-dc1-k8s-master
```

## 👷 Worker example
```bash
hostnamectl set-hostname ngd-dc1-k8s-worker01
```

## ✅ Verify
```bash
hostnamectl
hostname
```

---

# 2️⃣ Configure DNS / Hosts Resolution

Each node must be able to resolve:

- its own hostname
- the master hostname
- `kubeapi.nagad.com`

## ✅ Verify current resolution
```bash
getent hosts $(hostname)
getent hosts kubeapi.nagad.com
getent hosts ngd-dc1-k8s-master
```

## 🛠️ If DNS is not available, add `/etc/hosts`

### Example
```bash
cat <<EOF >> /etc/hosts
192.168.20.126   kubeapi.nagad.com
192.168.20.126   ngd-dc1-k8s-master
192.168.20.127   ngd-dc1-k8s-worker01
192.168.20.128   ngd-dc1-k8s-worker02
EOF
```

## ✅ Verify
```bash
getent hosts kubeapi.nagad.com
getent hosts ngd-dc1-k8s-master
```

# 3️⃣ Disable Swap

```bash
swapoff -a
sed -i '/swap/d' /etc/fstab
```

## ✅ Verify
```bash
swapon --show
free -h
```

---

# 4️⃣ Load Required Kernel Modules

```bash
cat <<EOF > /etc/modules-load.d/k8s.conf
overlay
br_netfilter
EOF

modprobe overlay
modprobe br_netfilter
```

## ✅ Verify
```bash
lsmod | egrep 'overlay|br_netfilter'
```

---

# 5️⃣ Configure sysctl for Kubernetes

```bash
cat <<EOF > /etc/sysctl.d/k8s.conf
net.bridge.bridge-nf-call-iptables=1
net.bridge.bridge-nf-call-ip6tables=1
net.ipv4.ip_forward=1
EOF

sysctl --system
```

## ✅ Verify
```bash
sysctl net.ipv4.ip_forward
sysctl net.bridge.bridge-nf-call-iptables
sysctl net.bridge.bridge-nf-call-ip6tables
```

---

# 6️⃣ Ensure SELinux is Enforcing

## ✅ Verify
```bash
getenforce
grep '^SELINUX=' /etc/selinux/config
```

Expected:
```text
Enforcing
SELINUX=enforcing
```

## 🛠️ Fix if needed
```bash
sed -i 's/^SELINUX=.*/SELINUX=enforcing/' /etc/selinux/config
reboot
```

---

# 7️⃣ Enable cgroups v2

Required for Kubernetes 1.35.

```bash
grubby --update-kernel=ALL --args="systemd.unified_cgroup_hierarchy=1"
reboot
```

## ✅ Verify after reboot
```bash
stat -fc %T /sys/fs/cgroup
mount | grep cgroup
cat /proc/cmdline
```

Expected:
- `cgroup2fs`
- `cgroup2` mounted on `/sys/fs/cgroup`
- kernel cmdline contains `systemd.unified_cgroup_hierarchy=1`

---

# 8️⃣ Optional Kernel Upgrade to 5.15 LTS

> Recommended only if your environment supports booting the ELRepo kernel cleanly.  
> If not, continue with the vendor RHEL kernel after enabling cgroups v2.

## Install ELRepo
```bash
rpm --import https://www.elrepo.org/RPM-GPG-KEY-elrepo.org
dnf install -y https://www.elrepo.org/elrepo-release-8.el8.elrepo.noarch.rpm
```

## Install `kernel-lt`
```bash
dnf --enablerepo=elrepo-kernel install -y kernel-lt
```

## Check installed kernels
```bash
grubby --info=ALL | egrep '^index|^kernel'
```

## Set the ELRepo kernel as default
```bash
grubby --set-default /boot/vmlinuz-5.15.202-1.el8.elrepo.x86_64
grubby --default-kernel
```

## Reboot
```bash
reboot
```

## ✅ Verify after reboot
```bash
uname -r
stat -fc %T /sys/fs/cgroup
getenforce
```

Expected:
- `5.15.x`
- `cgroup2fs`
- `Enforcing`

> If the server does not boot with the new kernel, revert to the previous RHEL kernel from GRUB / console.

# 9️⃣ Configure Proxy

## System-wide environment
```bash
cat <<EOF >> /etc/environment
HTTP_PROXY=http://192.168.20.200:9999
HTTPS_PROXY=http://192.168.20.200:9999
NO_PROXY=localhost,127.0.0.1,10.0.0.0/8,192.168.0.0/16,.cluster.local,kubeapi.nagad.com
EOF
```

## DNF proxy
```bash
grep -q '^proxy=' /etc/dnf/dnf.conf || echo 'proxy=http://192.168.20.200:9999' >> /etc/dnf/dnf.conf
```

## ✅ Verify
```bash
grep -i proxy /etc/dnf/dnf.conf
```

# 🔟 Configure CRI-O Repository

```bash
CRIO_VERSION=v1.35

cat <<EOF > /etc/yum.repos.d/crio.repo
[cri-o]
name=CRI-O
baseurl=https://download.opensuse.org/repositories/isv:/cri-o:/stable:/${CRIO_VERSION}/rpm/
enabled=1
gpgcheck=1
gpgkey=https://download.opensuse.org/repositories/isv:/cri-o:/stable:/${CRIO_VERSION}/rpm/repodata/repomd.xml.key
EOF

dnf clean all
dnf makecache
dnf repolist
dnf list cri-o
```

## ✅ Verify
You should see `cri-o.x86_64` available.

---

# 1️⃣1️⃣ Install and Start CRI-O

```bash
dnf install -y cri-o
systemctl daemon-reload
systemctl enable --now crio
systemctl status crio
```

## ✅ Verify
```bash
crio --version
systemctl is-active crio
ls -l /var/run/crio/crio.sock
```

---

# 1️⃣2️⃣ Configure CRI-O cgroup Driver

```bash
mkdir -p /etc/crio/crio.conf.d

cat <<EOF > /etc/crio/crio.conf.d/02-cgroup-manager.conf
[crio.runtime]
cgroup_manager = "systemd"
EOF

systemctl restart crio
```

## ✅ Verify
```bash
grep -R "cgroup_manager" /etc/crio/crio.conf /etc/crio/crio.conf.d 2>/dev/null
```

Expected:
```text
cgroup_manager = "systemd"
```

---

# 1️⃣3️⃣ Configure Proxy for CRI-O

```bash
mkdir -p /etc/systemd/system/crio.service.d

cat <<EOF > /etc/systemd/system/crio.service.d/proxy.conf
[Service]
Environment="HTTP_PROXY=http://192.168.20.200:9999"
Environment="HTTPS_PROXY=http://192.168.20.200:9999"
Environment="NO_PROXY=localhost,127.0.0.1,10.0.0.0/8,192.168.0.0/16,.cluster.local,kubeapi.nagad.com"
EOF

systemctl daemon-reload
systemctl restart crio
```

## ✅ Verify
```bash
systemctl status crio
```

---

# 1️⃣4️⃣ Install `crictl`

## Option A — from repo after Kubernetes repo is added later
```bash
dnf install -y cri-tools
```

## Option B — manual install
```bash
VERSION=v1.35.0
curl -LO https://github.com/kubernetes-sigs/cri-tools/releases/download/${VERSION}/crictl-${VERSION}-linux-amd64.tar.gz
tar -xvf crictl-${VERSION}-linux-amd64.tar.gz
mv crictl /usr/local/bin/
chmod +x /usr/local/bin/crictl
```

## Configure `crictl`
```bash
cat <<EOF > /etc/crictl.yaml
runtime-endpoint: unix:///var/run/crio/crio.sock
image-endpoint: unix:///var/run/crio/crio.sock
timeout: 10
debug: false
EOF
```

## ✅ Verify
```bash
crictl info
```

Expected highlights:
- `"CgroupManagerName": "systemd"`
- `"SELinux": true`
- `RuntimeReady = true`

> `NetworkReady = false` before CNI installation is expected.

# 1️⃣5️⃣ Configure Kubernetes Repository

```bash
cat <<EOF > /etc/yum.repos.d/kubernetes.repo
[kubernetes]
name=Kubernetes
baseurl=https://pkgs.k8s.io/core:/stable:/v1.35/rpm/
enabled=1
gpgcheck=1
gpgkey=https://pkgs.k8s.io/core:/stable:/v1.35/rpm/repodata/repomd.xml.key
exclude=kubelet kubeadm kubectl cri-tools kubernetes-cni
EOF

dnf clean all
dnf makecache
```

---

# 1️⃣6️⃣ Install Kubernetes Packages

```bash
dnf install -y kubelet kubeadm kubectl --disableexcludes=kubernetes
systemctl enable --now kubelet
```

## ✅ Verify
```bash
rpm -qa | egrep 'kubelet|kubeadm|kubectl|cri-tools|kubernetes-cni'
```

---

# 1️⃣7️⃣ Configure kubelet to Use CRI-O

```bash
mkdir -p /etc/systemd/system/kubelet.service.d

cat <<EOF > /etc/systemd/system/kubelet.service.d/20-cri-o.conf
[Service]
Environment="KUBELET_EXTRA_ARGS=--container-runtime-endpoint=unix:///var/run/crio/crio.sock"
EOF
```

## Configure kubelet proxy
```bash
cat <<EOF > /etc/systemd/system/kubelet.service.d/proxy.conf
[Service]
Environment="HTTP_PROXY=http://192.168.20.200:9999"
Environment="HTTPS_PROXY=http://192.168.20.200:9999"
Environment="NO_PROXY=localhost,127.0.0.1,10.0.0.0/8,192.168.0.0/16,.cluster.local,kubeapi.nagad.com"
EOF
```

Apply:
```bash
systemctl daemon-reload
systemctl restart kubelet
systemctl status kubelet
```

> Before `kubeadm init` or `kubeadm join`, kubelet may show auto-restart. That is normal.
