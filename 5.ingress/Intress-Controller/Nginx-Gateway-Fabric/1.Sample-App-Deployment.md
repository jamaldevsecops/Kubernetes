# 5️⃣ Deploy Applications

## 📄 app1.yaml

```yaml
apiVersion: apps/v1
kind: Deployment

metadata:
  name: app1
  namespace: app1-ns

spec:
  replicas: 2

  selector:
    matchLabels:
      app: app1

  template:
    metadata:
      labels:
        app: app1

    spec:
      containers:
      - name: nginx
        image: nginx

        ports:
        - containerPort: 80

---
apiVersion: v1
kind: Service

metadata:
  name: app1
  namespace: app1-ns

spec:
  selector:
    app: app1

  ports:
  - port: 80
    targetPort: 80
```

# 6️⃣ Configure HTTPRoutes

## 📄 app1-route.yaml

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: HTTPRoute

metadata:
  name: app1-route
  namespace: app1-ns

spec:
  parentRefs:
  - name: nagad-gateway
    namespace: nginx-gateway

  hostnames:
  - "app1.mydomain.com"

  rules:
  - backendRefs:
    - name: app1
      port: 80
```

# 🔐 Phase 2 — HTTPS Setup

---

# 📜 Certificate Files

Purchased SSL usually provides:

```text
server.crt
intermediate.crt
root.crt
private.key
```

---

# ⚠️ Correct Certificate Chain Order

```text
server.crt
intermediate.crt
root.crt
```

---

# 🛠️ Create Full Chain

```bash
cat server.crt intermediate.crt root.crt > fullchain.crt
```

---

# 🔑 Create TLS Secret

```bash
kubectl create secret tls nagad-com-tls \
  --cert=fullchain.crt \
  --key=private.key \
  -n nginx-gateway
```

---

# 📄 gateway-https.yaml

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway

metadata:
  name: nagad-gateway
  namespace: nginx-gateway

  annotations:
    metallb.io/address-pool: first-pool

spec:
  gatewayClassName: nginx

  addresses:
  - type: IPAddress
    value: 192.168.20.200

  listeners:

  - name: http
    protocol: HTTP
    port: 80

    allowedRoutes:
      namespaces:
        from: All

  - name: https
    protocol: HTTPS
    port: 443

    tls:
      mode: Terminate

      certificateRefs:
      - name: nagad-com-tls

    allowedRoutes:
      namespaces:
        from: All
```

---
