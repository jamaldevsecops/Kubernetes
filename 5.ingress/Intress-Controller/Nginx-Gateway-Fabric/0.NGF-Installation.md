# ⚠️ Common Engineering Confusions

## ❓ NGF Service Type

Many engineers expect:

```bash
ngf-nginx-gateway-fabric
```

to become `LoadBalancer`.

✅ This is WRONG.

The NGF controller service remains:

```text
ClusterIP
```

The actual LoadBalancer service is dynamically created after Gateway creation.

---

## ❓ Gateway vs HTTPRoute

| Resource | Responsibility |
|---|---|
| Gateway | Listener / VIP / Ports |
| HTTPRoute | Application Routing |

---

## ❓ TLS Certificate Chain Order

Wrong order causes:

- Browser trust issues
- Incomplete chain errors
- SSL validation failures

Correct order:

```text
server.crt
intermediate.crt
root.crt
```

# 📦 Phase 1 — HTTP Setup

---

# 1️⃣ Install Gateway API CRDs

```bash
kubectl apply -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.5.1/standard-install.yaml
```

---

# 🔍 Verify Gateway CRDs

```bash
kubectl get crds | grep gateway
kubectl describe gatewayclass nginx
```

Expected:

```text
gatewayclasses.gateway.networking.k8s.io
gateways.gateway.networking.k8s.io
httproutes.gateway.networking.k8s.io
```

---

# 2️⃣ Install NGINX Gateway Fabric

## 📄 values.yaml

```yaml
nginxGateway:
  replicas: 2
```

---

## 🚀 Install NGF

```bash
helm install ngf oci://ghcr.io/nginx/charts/nginx-gateway-fabric \
  --create-namespace \
  -n nginx-gateway \
  -f values.yaml
```

---

# 🔍 Verify NGF Installation

```bash
kubectl get pods -n nginx-gateway
kubectl get svc -n nginx-gateway
```

Expected:

```text
ngf-nginx-gateway-fabric   ClusterIP
```

✅ This is correct.

---

# 3️⃣ Create Gateway

## 📄 gateway-http.yaml

```yaml
apiVersion: gateway.networking.k8s.io/v1
kind: Gateway

metadata:
  name: nagad-gateway
  namespace: nginx-gateway

  annotations:
    metallb.io/address-pool: first-pool

spec:
  gatewayClassName: nginx

  addresses:
  - type: IPAddress
    value: 192.168.20.200

  listeners:
  - name: http
    protocol: HTTP
    port: 80

    allowedRoutes:
      namespaces:
        from: All
```

---

# 🚀 Apply Gateway

```bash
kubectl apply -f gateway-http.yaml
```

---

# 🔍 Verify Gateway

```bash
kubectl get gateway -n nginx-gateway
kubectl get svc -n nginx-gateway
```

Expected:

```text
PROGRAMMED=True
ADDRESS=192.168.20.200
```
