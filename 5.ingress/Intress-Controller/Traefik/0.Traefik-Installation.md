# ⚙️ Traefik Installation – Beginner to Production Guide

This document explains **how to install Traefik** in Kubernetes step by step. 

---

## 🌱 What This Guide Covers

You will learn:
- How Traefik is deployed in Kubernetes
- Recommended installation method (Helm)
- Production-safe defaults
- How to verify installation
- Common installation mistakes

---

## 🧠 How Traefik Is Installed (Mental Model)

In Kubernetes, Traefik runs as:

- A **Deployment** (Traefik pods)
- A **Service** (LoadBalancer / NodePort)
- A **CRD Controller** (IngressRoute, Middleware, etc.)

```
Kubernetes Cluster
 ├─ Traefik Deployment
 ├─ Traefik Service (LB / NodePort)
 └─ Traefik CRDs
```

---

## 📋 Prerequisites

Before installing Traefik, make sure you have:

- Kubernetes cluster (v1.22+ recommended)
- `kubectl` configured
- `helm` v3 installed
- Cluster admin permissions

Check:
```bash
kubectl version --short
helm version
```

---

## ⭐ Recommended Installation Method: Helm

Helm is the **official and recommended** way to install Traefik.

Why Helm?
- Easy upgrades
- Clean rollback
- Production-friendly
- CRDs managed correctly

---

## 1️⃣ Add Traefik Helm Repository

```bash
helm repo add traefik https://traefik.github.io/charts
helm repo update
```

---

## 2️⃣ Create Namespace

```bash
kubectl create namespace traefik
```

---

## 3️⃣ Basic Traefik Installation

```bash
helm install traefik traefik/traefik   --namespace traefik
```

This installs:
- Traefik Deployment
- Traefik Service
- Required CRDs
- RBAC

---

## 4️⃣ Verify Installation

```bash
kubectl get pods -n traefik
kubectl get svc -n traefik
```

Expected:
- Traefik pods in `Running` state
- Service type `LoadBalancer` (cloud)
- External IP assigned

---

## 🌐 Access Traefik (Quick Test)

### Port-forward (safe & simple)

```bash
kubectl -n traefik port-forward svc/traefik 9000:9000
```

Dashboard:
```
http://localhost:9000/dashboard/
```

⚠️ Do NOT expose dashboard publicly without auth.

## ⚙️ Production Installation (Recommended)

Create a `values.yaml`:

```yaml
deployment:
  replicas: 2

providers:
  kubernetesCRD:
    enabled: true
  kubernetesIngress:
    enabled: false

ports:
  web:
    redirectTo:
      port: websecure
  websecure:
    tls:
      enabled: true

api:
  dashboard: true
  insecure: false

metrics:
  prometheus:
    enabled: true

logs:
  general:
    level: INFO
  access:
    enabled: true

resources:
  requests:
    cpu: 100m
    memory: 128Mi
  limits:
    cpu: 500m
    memory: 512Mi
```

Install / Upgrade:

```bash
helm upgrade --install traefik traefik/traefik   --namespace traefik   -f values.yaml
```

---

## 🔐 CRDs Installed by Traefik

Traefik automatically installs these CRDs:

- IngressRoute
- Middleware
- TLSOption
- TLSStore
- ServersTransport

Verify:
```bash
kubectl get crds | grep traefik
```

---

## 🔁 Upgrade Traefik

```bash
helm repo update
helm upgrade traefik traefik/traefik -n traefik
```

No downtime if replicas ≥ 2.

---

## 🧹 Uninstall Traefik

```bash
helm uninstall traefik -n traefik
kubectl delete namespace traefik
```

⚠️ CRDs may remain (intentional, to avoid data loss).

---

## 🚨 Common Installation Mistakes

❌ Installing without CRDs  
❌ Using NodePort unnecessarily  
❌ Exposing dashboard insecurely  
❌ Single replica in production  
❌ Forgetting resource limits  

---

## 🧠 Production Checklist

- [ ] Helm-based install
- [ ] Replicas ≥ 2
- [ ] Dashboard protected
- [ ] Metrics enabled
- [ ] Access logs enabled
- [ ] Resource limits defined
