# ⚙️ Traefik Installation – Beginner to Production Guide (MetalLB Enabled)

This document explains how to install **Traefik Ingress Controller** in Kubernetes with **explicit external IP assignment (MetalLB)**.

---

# 🌱 What This Guide Covers

You will learn:

* How Traefik is deployed in Kubernetes
* How to assign a **static external IP (MetalLB)**
* Production-safe installation using Helm
* How to verify and access Traefik

---

# 🧠 How Traefik Works (Mental Model)

In Kubernetes, Traefik runs as:

* A **Deployment** (Traefik pods)
* A **Service (LoadBalancer)** → assigned by MetalLB
* A **CRD Controller**

```
Client
  ↓
MetalLB External IP (VIP)
  ↓
Traefik Service (LoadBalancer)
  ↓
Traefik Pods
  ↓
Backend Services
```

---

# 📋 Prerequisites

Ensure the following:

* Kubernetes cluster (v1.22+)
* `kubectl` configured
* `helm` v3 installed
* MetalLB installed and configured
* Available IP (example): `192.168.20.131`

Check:

```bash
kubectl version --short
helm version
kubectl get svc -A
```

---

# ⭐ Installation Method: Helm (Recommended)

Helm provides:

* Easy upgrades
* Clean rollback
* Proper CRD management
* Production-ready deployment

---

# 1️⃣ Add Traefik Helm Repository

```bash
helm repo add traefik https://traefik.github.io/charts
helm repo update
```

---

# 2️⃣ Create Namespace

```bash
kubectl create namespace traefik
```

---

# ⚙️ 3️⃣ Production Configuration (values.yaml)

Create `values.yaml`:

```yaml
deployment:
  replicas: 2

providers:
  kubernetesCRD:
    enabled: true
  kubernetesIngress:
    enabled: false

service:
  type: LoadBalancer

  # 🎯 Explicit MetalLB IP assignment
  spec:
    loadBalancerIP: 192.168.20.131

ports:
  web:
    expose:
      default: true

  websecure:
    http:
      tls:
        enabled: false

api:
  dashboard: true
  insecure: false

metrics:
  prometheus:
    enabled: true

logs:
  general:
    level: INFO
  access:
    enabled: true

resources:
  requests:
    cpu: 100m
    memory: 128Mi
  limits:
    cpu: 500m
    memory: 512Mi
```

---

# 🚀 4️⃣ Install Traefik

```bash
helm upgrade --install traefik traefik/traefik \
  --namespace traefik \
  -f values.yaml
```

---

# 🔍 5️⃣ Verify Installation

```bash
kubectl get pods -n traefik
kubectl get svc -n traefik -o wide
```

---

## ✅ Expected Output

```bash
NAME      TYPE           EXTERNAL-IP
traefik   LoadBalancer   192.168.20.131
```

✔ External IP should match the configured MetalLB IP

---

# 🌐 6️⃣ Access Traefik

## ▶️ From network

```bash
curl http://192.168.20.131
```

---

## ▶️ Dashboard (secure access recommended)

```bash
kubectl -n traefik port-forward svc/traefik 9000:9000
```

Open:

```
http://localhost:9000/dashboard/
```

⚠️ Always secure dashboard before exposing externally.

---

# 🔐 7️⃣ CRDs Installed

Verify:

```bash
kubectl get crds | grep traefik
```

Installed CRDs include:

* IngressRoute
* Middleware
* TLSOption
* TLSStore
* ServersTransport

---

# 🔁 8️⃣ Upgrade Traefik

```bash
helm repo update
helm upgrade traefik traefik/traefik -n traefik
```

✔ Zero downtime with replicas ≥ 2

---

# 🧹 9️⃣ Uninstall

```bash
helm uninstall traefik -n traefik
kubectl delete namespace traefik
```
