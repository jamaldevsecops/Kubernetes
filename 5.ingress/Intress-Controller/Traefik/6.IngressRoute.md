## 🧠 How Traefik Is Installed (Mental Model)

In Kubernetes, Traefik runs as:

-   A **Deployment** (Traefik pods)
-   A **Service** (LoadBalancer / NodePort)
-   A **CRD Controller** (IngressRoute, Middleware, etc.)

```
    Kubernetes Cluster
     ├─ Traefik Deployment
     ├─ Traefik Service (LB / NodePort)
     └─ Traefik CRDs

------------------------------------------------------------------------

## 📋 Prerequisites

Before installing Traefik, make sure you have:

-   Kubernetes cluster (v1.22+ recommended)
-   `kubectl` configured
-   `helm` v3 installed
-   Cluster admin permissions

Check:

``` bash
kubectl version --short
helm version
```

------------------------------------------------------------------------

## ⭐ Recommended Installation Method: Helm

Helm is the **official and recommended** way to install Traefik.

### Why Helm?

-   Easy upgrades
-   Clean rollback
-   Production-friendly
-   CRDs managed correctly

------------------------------------------------------------------------

## 1️⃣ Add Traefik Helm Repository

``` bash
helm repo add traefik https://traefik.github.io/charts
helm repo update
```

------------------------------------------------------------------------

## 2️⃣ Create Namespace

``` bash
kubectl create namespace traefik
```

------------------------------------------------------------------------

## 3️⃣ Basic Traefik Installation

``` bash
helm install traefik traefik/traefik --namespace traefik
```

------------------------------------------------------------------------

## ⚙️ Production Installation (Recommended)

Create a `values.yaml`:

``` yaml
deployment:
  replicas: 2

providers:
  kubernetesCRD:
    enabled: true
  kubernetesIngress:
    enabled: false

ports:
  web:
    expose:
      default: true

  websecure:
    http:
      tls:
        enabled: false

  # Custom App on Port 4001
  app1:
    port: 4001
    exposedPort: 4001
    expose:
      default: true

  # Custom App on Port 4002
  app2:
    port: 4002
    exposedPort: 4002
    expose:
      default: true

api:
  dashboard: true
  insecure: false

metrics:
  prometheus:
    enabled: true

logs:
  general:
    level: INFO
  access:
    enabled: true

resources:
  requests:
    cpu: 100m
    memory: 128Mi
  limits:
    cpu: 500m
    memory: 512Mi
```

Install / Upgrade:

``` bash
helm upgrade --install traefik traefik/traefik --namespace traefik -f values.yaml
```

## ➕ Exposing Applications on Default Port

Example IngressRoute:

``` yaml
apiVersion: traefik.io/v1alpha1
kind: IngressRoute
metadata:
  name: myapp
spec:
  entryPoints:
    - web
  routes:
    - match: Host(`myapp.apsis.localnet`)
      kind: Rule
      services:
        - name: myapp
          port: 3000
```

Example Service (3000):

``` yaml
apiVersion: v1
kind: Service
metadata:
  name: myapp
spec:
  selector:
    app: myapp
  ports:
    - port: 3000
      targetPort: 3000
```


## ➕ Exposing Applications on Custom Ports

Example IngressRoute:

``` yaml
apiVersion: traefik.io/v1alpha1
kind: IngressRoute
metadata:
  name: app1
spec:
  entryPoints:
    - app4001
  routes:
    - match: Host(`app1.apsis.localnet`)
      kind: Rule
      services:
        - name: app1
          port: 4001
```

Example Service (4001):

``` yaml
apiVersion: v1
kind: Service
metadata:
  name: app1
spec:
  selector:
    app: app1
  ports:
    - port: 4001
      targetPort: 4001
```


Access:

http://app1.apsis.localnet:4001

## ✅ Summary

-   Helm is the best way to install Traefik
-   Production requires proper `values.yaml`
-   Custom external ports require new entryPoints
-   IngressRoute binds traffic to entryPoints
-   Traefik Service type determines external reachability
